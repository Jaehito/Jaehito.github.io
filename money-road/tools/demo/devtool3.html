추가 02

📋 템플릿 — 이게 우리 작업 고리입니다

헤더의 📋를 누르면 열립니다. 지금 값 전부가 JSON 한 덩이로 나오고, 길게 눌러 복사해서 넘겨주시면 제가 코드에 박고 시뮬로 검증한 뒤 배포합니다.

  • 1JSON은 설정만 담습니다. 측정값(초반↑ 몇 % 같은 것)은 넣지 않습니다 — 제가 받아서 직접 다시 재는 쪽이 안전합니다.
  • 2슬롯은 전부 초기화에도 안 지워집니다. 저장 키를 _devtpl로 따로 두고 초기화 대상에서 뺍니다. 맞춰둔 값을 실수로 잃으면 그 시간이 통째로 날아갑니다.
  • 3불러오기는 붙여넣기로도 됩니다. 제가 "이 값 한번 써보세요" 하고 JSON을 드리면 그대로 넣어보실 수 있습니다 — 양방향입니다.
  • 4복사는 클립보드 API 대신 전체 선택으로 갑니다. 모바일에서 클립보드 권한이 막히는 경우가 있어서, 선택해두면 길게 눌러 복사가 확실합니다.
